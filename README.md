# Ripasso

Offline-first vocabulary flashcards with spaced repetition (Leitner boxes), built as a small installable web app.

- Paste cards as `front,back` lines (split at the first comma or tab)
- Four answer buttons; cards you know well come back less often
- Data stays in your browser; backup/restore as JSON text
- Add to the iPhone home screen via Safari → Share → "Add to Home Screen"

No build step: open `index.html` or serve the folder.
